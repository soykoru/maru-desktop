# KORU Live

**KORU Live** conecta tu directo de TikTok con tus juegos, tu pantalla y tu chat: cada regalo, like, comentario o
comando puede hacer que pase algo de verdad en Minecraft, Terraria, Roblox y más; mostrar alertas, metas y rankings en
tus overlays; leer el chat en voz alta; pedir canciones o responder con IA.

Más información y la tienda: **[soykoru.stream](https://soykoru.stream)**

## Descargar

La versión más nueva siempre está en **[Releases → la última](https://github.com/soykoru/maru-desktop/releases/latest)**:
descarga `KORU-Live-Setup-<versión>.exe` y ábrelo. La app se actualiza sola cuando sale una versión nueva.

- Windows 10 u 11, de 64 bits.
- Español, English y Português.
